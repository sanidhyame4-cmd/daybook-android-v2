# Source notes

Starting point: the user-uploaded `Daybook (5).html`. The original source uses `localStorage` key `daybook1`, stores task reminder minutes in `task.rem`, and uses backup envelope `{app: "daybook", schema: 4, exportedAt, data}`. Original export depended on `claude.use('downloads')`; AI insights depend on `claude.use('sample')`. These were identified in the uploaded file before the Android wrapper was added.

No server, cloud database, analytics, AI API key, or PC sync service has been added.
